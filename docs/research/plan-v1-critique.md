## C. "Confirmed" claims that still look shaky (and the research recommendation did not absorb the verifier's corrections)

1. **OHM tiles/style (confirmed, medium).** Recommendation still says load `openhistoricalmap.github.io/map-styles/main/main.json` + `/maps/osm/{z}/{x}/{y}.pbf`. The verifier shows `/maps/osm/` is a deprecated Varnish alias that already broke once (June 2026), the GH-Pages style is from Jan 2025 and references 10 source-layers that no longer exist (labels silently vanish), and the whole OHM stack migrated to a new cluster on Oct 5-6 2026. Fix: `https://unpkg.com/@openhistoricalmap/map-styles@0.9.19/dist/historical/historical.json` and `/maps/ohm/`; pin the version; budget for OHM being down this week.
2. **maplibre-gl-dates on MapLibre 6.x.** Architecture research pins maplibre-gl 6.13; OHM's own embed pins ^5.24 and *reverted* a 6.2 bump in Aug 2026. Nobody tested the combination. Fix: start on maplibre-gl 5.x, or add a 1-line Vitest that calls `filterByDate` against the unpkg style under 6.x before committing to 6.
3. **Overpass (contested → effectively refuted for this use).** Recommendation still makes it the second call per address with failover to `overpass.private.coffee` (frozen since May 2026, stopped answering) and `kumi.systems` (same host, dead). Fix: remove Overpass from the per-address path entirely (see A); if kept for anything, main server only, no retries, ≤100/day aggregate.
4. **OpenCage (contested).** Recommendation keeps it as a keyed fallback; the refuting vote shows OpenCage's FAQ says the free trial is for testing, not production, and the key cannot be origin-restricted. Fix: drop it; Photon is the one-file swap-in.
5. **Wikipedia Action API "ONE call" example.** Marked confirmed, but the verifier shows it returns coordinates for only 10 of 50 hits (`colimit` default 10), extracts for max 20 (`exlimit`), no `dist` in generator mode without `codistancefrompoint`, and `prop=sections` is deprecated for `tocdata`. The recommendation repeats the broken example. Fix the example before anyone copies it into `wiki.ts`.
6. **WDQS.** Confirmed, but on a published sunset path (degrade Feb 2027, decommission ~June 2027) and `wikibase:around`/`wikibase:label` are not supported by the QLever successor. Both the research and the UX put SPARQL-around at the centre of inner-ring discovery. Fix: make Wikipedia `generator=geosearch` + `ppprop=wikibase_item` the primary "items near the point" source (same data, no SPARQL), keep SPARQL optional, and write Query C/D without the label service.
7. **Nominatim.** Confirmed, but two things are glossed: the policy's new "Usage in LLMs" clause (LLM-generated code must comply; use permitted only where the developer made a deliberate, informed decision and is directly responsible) applies squarely to this project, and the 1 req/s limit is per *site*, not per visitor. Fix: README checkbox the owner signs off on, endpoint in `config/sources.ts` so it can be switched on request, and the 4-reverse-call cache keyed by city so most visitors hit zero Nominatim calls beyond `/search`.
8. **GPlates.** Confirmed, but error responses (400 for a time outside the model span) carry no CORS header, so the browser sees an opaque TypeError, and `&fc` returns `valid_time`/`pid`, not `begin_time`/`end_time`. More important: the UX plans ~20 GPlates calls per address while scrubbing, on a server with an unpublished per-IP throttle. Fix: one call with `times=1,2.6,5.3,...,539` (the `times` list parameter exists per the verifier) → 1 request per address, cached.
9. **Macrostrat "rock under your house".** The map unit is the *mapped surface* unit, which in valleys and coastal plains is Quaternary alluvium (0.01 Ma), not bedrock, so the "rock forming right now" callout would fire at 10,000 years for many addresses. Fix: also fetch `/columns?lat&lng` → `/units?col_id` and show the oldest/bedrock unit; word the card "the ground mapped at this spot".
10. **LOC (confirmed, medium).** The flagship newspaper example silently ignores `qs`, `start_date`, `location_state` without `searchType=advanced`. Fix the example.
11. **NRHP (confirmed, medium).** Layers 0 and 1 are disjoint (districts and NHLs only in layer 1), `STATUS` includes "Removed". Fix: union both layers, `where=STATUS='Listed'`.

## E. Legal / policy landmines not called out

1. **Commons attribution on thumbnails.** The winner shows credit only on the expanded Chapter sheet; CC BY/BY-SA requires attribution wherever the image appears. Fix: 1-line caption (Artist · License · link) under every card image.
2. **Hero "one-sentence biography".** Must be assembled from CC0 (Wikidata) and CC BY (Macrostrat/GPlates) facts only; any paraphrase of Wikipedia prose makes the sentence CC BY-SA share-alike. Say so in `story.ts`.
3. **Bundled plate frames.** Pre-rendering coastlines from the PALEOMAP model and committing them to the repo brings Scotese's non-commercial terms into the repo; MERDITH2021 and MULLER2019 are CC BY 4.0 on Zenodo. Fix: bundle only CC BY models and cite the DOI in About.
4. **`gplates` npm package is GPL-2.0-only.** Bundling it into the site makes the site's JS GPL; fine for a hobby site but must be a conscious choice. The `times=` batch call avoids needing it.
5. **OSM raster as "today's basemap".** The winner's fallback map is "today's OpenStreetMap basemap rendered in sepia", i.e. tile.openstreetmap.org, which the tile policy only tolerates for light use with Referer and attribution. Fix: ghost layer = OpenFreeMap positron with a CSS `filter: grayscale(1) sepia(.3)` on the map canvas (or desaturated paint properties), OSM raster only as last-resort fallback.
6. **Native Land** (if ever added): non-commercial, key must sit in client code, and drawing undated territory polygons on a time slider risks the treaty's "must not misrepresent" clause. Keep out of v1; if added, show only at "now" with their disclaimer.
7. **Derived-database share-alike.** Caching OSM responses per visitor is fine; if a build step ever precomputes a city-wide index from OSM data, that is an ODbL derivative database. Not planned; note it in CONTRIBUTING.
8. **Privacy.** Covered in UX, but add: URL hash contains a friend's home coordinates (say so on share), owner's own address as an example chip is a doxxing risk, and the "contact identifier" (Nominatim `email=`, `Api-User-Agent`) should be the repo URL, not a personal email in public source.
