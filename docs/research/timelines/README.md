# Washington timelines (from Plan v2, fact-checked)

- `wa-deeptime-events.json`: 36 geologic and natural-history events, Precambrian to today plus a qualitative 50 Ma projection.
- `wa-history-events.json`: 115 human-history events, earliest known presence to today, with per-city founding dates.

Each event: id, title, when, start_years_ago, end_years_ago, region (list), lat/lon where relevant, summary, at_your_spot template, sources, confidence. These are the Plan v2 appendices (docs/PLAN-v2.md) after the fact-checkers' corrections. They move to public/data/events/ when the time dial (phase 2) is built.
